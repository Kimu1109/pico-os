## ミュージックアプリ(プレイリスト・リピート・ミックス)(`MusicScene` / `widgets/apps/MusicPlayerPanel` / `apps/music/Play_Queue.hpp`) (2026-10-10)

SUMMARY.md #11の「ミュージックアプリ」を作り直したもの。

- **プレイリスト = `/music/`の直下のフォルダ**(ファイルでは持たない)。中の`*.mml`/`*.wav`/`*.mp3`(2026-10-29から)を名前順。フォルダは名前順に16個まで、
  1つのプレイリストは64曲まで(`PlayQueue::kMax`)。1段より深いフォルダは見ない。最初の画面(ライブラリ)は「すべての曲」(直下+全部のフォルダの曲)と
  フォルダの一覧で、直下に置いた曲は「すべての曲」にだけ出る。一覧の名前は拡張子を落とす。
- **曲は1回タップで鳴らす**(ScrollListの「1回目は選ぶ」を、`OSData::isTouchStart`のときは鳴らす扱いにした。キー/コントローラーで↑↓しているときは
  選ぶだけで、決定で鳴らす)。鳴らした時点のプレイリストが再生の順番になり(`queue_tracks`にコピー)、別のプレイリストを見に行っても続く。
  鳴っている曲/プレイリストは一覧で緑。プレイリストの画面の[全曲]は並びの頭から(ミックスなら混ぜた並びのどれか)。
- **順番(`PlayQueue`、ヘッダだけ・描画にもSDにも依存しない)**: 順番通り/ミックス(Fisher-Yates、今の曲を先頭に置く。切り替えても今の曲は変わらない)、
  リピート しない/全曲/1曲(しない=最後の次で止まる、全曲=頭へ戻りミックスなら混ぜ直す(直前の曲を先頭にしない)、1曲=終わったら同じ曲。
  1曲でも「次へ」は次の曲)。「前へ」は鳴らし始めて3秒より後なら今の曲の頭へ。`/sys/music.cfg`の`shuffle`/`repeat = off|all|one`に覚える(無くてよい)。
- **曲の終わり**: `onUpdate()`が「鳴らしていたのに`MusicPlaying()`/`WavPlaying()`が偽」を見て次へ。**MMLの`L`で戻る曲(終わりが無い)は、
  `MusicTotalMs()`(戻るまでの長さ)を過ぎたら次へ**(1曲リピートの間は繰り返し続け、時間は1周の中の位置と「ループ」を出す)。
  **読めない曲**: 利用者が選んだ曲(タップ・前/次・再生)なら止まって理由を赤で出し続け、曲の終わりで進んだ先・[全曲]なら8秒出して次へ飛ばす
  (続けて全部読めなければ止まる)。欄には頭しか入らないので「(タップで全文)」と出し、欄の文字をタップすると全文を`MsgDialog`(長ければ中でスクロール)で出す
  (2026-10-10、「理由が見切れて読めない」との指摘で)。読めなかった曲は一覧で赤。**2026-10-15から再生は`MusicService`(OS常駐)が持ち、アプリを閉じても鳴り続ける**(上の「バックグラウンド実行の枠組み」)。
- **下の「再生中」の欄(`MusicPlayerPanel`、118px)**: 曲名 / プレイリスト名・n/m曲目(読めない理由は赤で2行まで)/ `0:23 ━━●── 3:45` /
  ミックス・前・再生/一時停止・次・リピート。**子を持たずrender()で直接描く型**で、ボタンの絵(矢印・三角・ループの印)もfillTriangle/drawLine/
  drawRoundRectで描く(tablerに再生系のアイコンが無かったため。アイコンは足していない)。入っているモードは青+下の点、1曲リピートは「1」。
  シーンが毎フレーム`set*()`で流し込み、変わった行だけdirtyにする(時間は秒かつまみの画素が変わったとき)。描くのは合成の中だけ
  (`GameBoyView`と同じ)。シークバーはWAVだけ: 押した/動かした位置を描き、離したときに1回だけ`on_seek`(SDを読み直すため)。
  キー/コントローラー: 上下でシークバー⇔ボタンの行、左右でボタン(シークバーでは10秒戻る/進む)、決定で押す(枠は自分で描く`drawsOwnFocus`)。
  物理キーボード: `n`次 `p`前 `k`再生/一時停止 `s`ミックス `r`リピート(`MusicScene::onKey()`)。
- `WidgetType::MusicPlayerPanel`を末尾へ足した。シーン本体は約7KB(曲の控え64件×2)。
- **ついでに直したもの(`gui/ScopedClip.hpp`)**: 合成の外の`render()`(`Widget::update()`がクリップを空にして書き込みを捨てている)で`ScopedClip`を使うと、
  空のクリップも幅0で返るので「クリップ無し」と取り違え、部品の矩形いっぱいへ広げた上、抜けるときの`clearClipRect()`で**その後の描画まで素通し**に
  なっていた(ScrollListのアイコン→文字が、dirty矩形の外=一覧の下の行へ描かれ、`PICOOS_VERIFY_LCD=1`で液晶と食い違った。どのScrollListでも、
  一番下に半分見えている項目があると起きる)。`PICO_GFX::render_suppressed`の間は空のクリップのまま描かせ、空へ戻すようにした。
- 検証: `play_queue_test`(run.sh の media)、PCビルドの`--tap`/`--shot`+標準入力の`key`の行(`PICOOS_VERIFY_LCD=1`で食い違い0): ライブラリ→プレイリスト→
  1回タップで再生、ループするMMLが1周で次のWAVへ進みリピートしないで止まる、読めないMMLの理由の表示と飛ばし、ミックス+[全曲]、`n`/`r`、
  リピート全曲で頭へ戻る、フォーカスで一覧→再生中の欄、`music.cfg`の保存。再生・シークバー・リピートは**実機で確認済み(2026-10-25)**。
- 曲と曲の間は空けない(2026-11-05、上の「曲と曲の間を空けない」)。スリープタイマーは下の「スリープタイマー」。
  ロック画面からも前/再生/次を操作できる(`os-services.md`「ロック画面の再生操作」)。
- タグ(アーティスト別・アルバム別)は下の「曲のタグと索引」、電源を切っても続きからは「続きから鳴らす」(2026-11-05)。
- 未: 曲の並べ替え・プレイリストの編集(フォルダを母艦で作る前提)、アルバムアート。(アプリを閉じても鳴り続ける再生は2026-10-15に入った)

## スリープタイマー (`MusicService::SetSleepTimer` / `SetSleepAtTrackEnd` / `MusicScene` の[⌛]) (2026-11-05)

音楽再生に特化した版の強化の3つ目。寝る前に鳴らして、決めた時間か今の曲の終わりで止める。

- **選び方**: ミュージックアプリの上の段の[⌛](全曲のボタンの左。無ければ右端)→ `PickerDialog` の Choice で「オフ / 15・30・45・60・90分後に止める /
  この曲の終わりで止める」。動いている間はボタンが⌛の代わりに青い文字で残り(「23分」、切り上げ)か「曲末」になる(`Button` はアイコンか文字の
  どちらかを描くので、`Button::clearIcon()` を足して切り替える)。ロック画面の日付の行にも「・23分で停止」/「・曲の終わりで停止」を出す。
- **時間で止める(Timer)**: `MusicService::Update()` が締め切り(`millis()`)を見る。最後の `kSleepFadeMs`(8秒)はWAV/MP3の音量を
  `SoundFunctions::WavSetVolume()`(新設。列の音量で、2コア目が足すときに掛かるので先読みした分にも効く)で100→0へ下げ、時間になったら止める
  (`StopSound()`。順番は残るので、再生を押せば続きから)。MMLは小さくせずに止める。一時停止の間も時間は進む(止まっていれば締め切りで止まるだけ)。
  リピート全曲・1曲で鳴り続けていても止まる。
- **この曲の終わりで(TrackEnd)**: 曲の終わりで次へ進むところ(`Advance(false)`)で止める。次の曲を同じ列へ続けて積む予約(上の「曲と曲の間を空けない」)は
  しない(`PlanNext()` が見送る)・予約済みなら取り消す(もう続けて積んだ後なら、その次の曲の終わりで止まる)。利用者の「次へ」は進む。
- **切れるとき**: 止まった・利用者が止めた(`Stop()`/`Release()`)・他のアプリに音を取られた・最後の曲で終わった・読めずに止まった(どれも `StopSound()`)。
  小さくしている途中で取り消したら100へ戻す。状態は `MusicService` の静的な変数(確保しない。`st` を返しても消えない)。
- スリープ(電源)との関係: 鳴っている間はスリープに入らない(`PowerFunctions`)ので、タイマーで止まった後は、ふだんの操作の無い時間(`sleep-timeout`)でスリープに入る。
- 検証: `background_test`(1分のタイマーで時間までは鳴り・最後の8秒も鳴り・時間で止まり切れる・順番は残る・止めたら切れる・
  「曲の終わりで」は予約した次の曲へ続けず1曲目で止まり切れる・取り消せば次へ進む・「次へ」は進む)。PCビルド: [⌛]→「30分後に止める」で
  ボタンが「30分」、ロック画面の日付の行に「・30分で停止」。**実機では未確認(小さくしていく聞こえ方)(Todoist参照)**。

## 曲のタグと索引 (`sound/Audio_Tags` / `apps/music/Music_Library` / `/sys/music_index.bin`) (2026-11-05)

音楽再生に特化した版の強化の4つ目。MP3のタグ(曲名・アーティスト・アルバム・曲番号)を読み、アーティスト別・アルバム別に探せるようにした。

- **タグを読む(`AudioTagReader::Read()`)**: .mp3 の頭の ID3v2(v2.2・v2.3・v2.4)の TIT2・TPE1・TALB・TRCK(v2.2 は TT2・TP1・TAL・TRK)。
  無い項目は終わりの ID3v1(v1.1 の曲番号も)で埋める。**ファイル全体は読まない**: フレームの見出しを順に読み、要る4つの中身(各256バイトまで)
  だけを読んで、ほか(アルバムアートの APIC 等)は seek で飛ばす。4つそろえば終える。読まないもの: 圧縮・暗号化したフレーム、v2.2/v2.3 の
  タグ全体の非同期化(フレームの大きさの数え方が変わるため。ID3v1 へ回す)。v2.4 のフレームごとの非同期化は戻す(UTF-16 の BOM の FF の後に 00 が入る)。
  - 文字コード: 0=ISO-8859-1 / 1=UTF-16(BOM)/ 2=UTF-16BE / 3=UTF-8 を UTF-8 へ(`MailCharset` の Decoder・EncodeUtf8 を使う)。
    0 と ID3v1 は、日本のソフトが Shift_JIS をそのまま入れていることが多いので、**Shift_JIS として最後まで正しく、2バイト文字を含めば Shift_JIS**、
    そうでなければ ISO-8859-1 として読む。v2.4 の複数の値(0区切り)は最初の1つ。前後の空白を落とし、長ければ文字の切れ目で縮める(96バイト)。
  - .wav・.mml は読まない(曲名はファイル名のまま)。
- **索引 `/sys/music_index.bin`**: 頭16バイト("PMIX"・版1・記録の大きさ)+ 曲1つにつき260バイトの記録(フォルダ名48・ファイル名48・曲名56・
  アーティスト48・アルバム48・大きさ・更新日時(FAT)・曲番号)。最大512曲(約130KB)。RAMへは載せず、一覧を作るたびに頭から順に読む
  (512曲で130KBを1回読むだけ)。記録が決まった大きさなので、壊れても次の作り直しで直る(読めない頭なら無いのと同じ)。
- **作り直し(`StartIndexUpdate()`/`StepIndexUpdate()`)**: ミュージックアプリを開くと始め、開いている間 `onUpdate()` で1フレーム8msまで進める
  (画面を固めない。閉じたらやめ、作りかけの .tmp を消す。前の索引は残る)。前の索引の記録を、ハッシュ(フォルダ名/ファイル名の FNV)の表
  (開番地法1024枠、フォルダ名と合わせて約7KB。作り直す間だけ malloc)へ入れ、**同じフォルダ・名前・大きさ・更新日時の記録があればタグを読み直さずに写す**
  (タグを書き換えるソフトは余白に収めて大きさを変えないことがあるので、更新日時も見る)。新しい索引は .tmp へ書き、終わったら差し替える。
  差し替えるたびに `IndexRevision()` が増え、画面は今の一覧を作り直す。ファームに要る更新日時は `FsFile::getModifyDateTime()`
  (PCビルドは stat の mtime、ホストテストのスタブは `HostSd::mtimes`)。
- **画面(`MusicScene`)**: ライブラリの頭に「すべての曲・アーティスト・アルバム」、その後にフォルダ。アーティスト/アルバムの一覧(名前順、64件まで、
  タグの無い曲は「不明なアーティスト/アルバム」)→ その曲(アルバムは曲番号→ファイル名、アーティストはアルバム名→曲番号→ファイル名)。
  一覧・再生中の欄・ロック画面・ホームのウィジェットの曲名は、タグの曲名があればそれ(`Track::title`、`MusicService::TrackTitle()`)。
  フォルダの一覧も索引から曲名を埋める(`FillTitles()`)。アーティスト/アルバムの並びも `MusicService` の順番(`kPlaylistArtist/kPlaylistAlbum`、
  `playlist_key` にタグの名前)になり、閉じて開き直すとその並びを開く。アルバムのアイコンは円(tabler の disc を足さず `IconID::Circle`)。
- 曲・フォルダを集める処理(`ScanFolders()`/`ScanTracks()`)は `MusicScene` から `MusicLibrary` へ移した(「続きから」が画面無しで同じ並びを作るため)。
- 検証: `music_library_test`(media。文字コード5種と Shift_JIS の見分け・曲番号・v2.3(5KBのアルバムアートを先に置いても飛ばす)・v2.4(128バイト以上の
  syncsafe・長さの印・非同期化)・v2.2・圧縮したフレームは読まず ID3v1(Shift_JIS・v1.1)で埋める・タグ無し/.wav は false・索引を少しずつ作る・
  アーティスト/アルバムの一覧と曲の並び・曲名を埋める・大きさと更新日時が同じなら写し変われば読み直す・消した曲・無いフォルダ・やめても前の索引が残る・
  壊れた索引・UTF-8 を途中で切らない)。PCビルド: ffmpeg でタグを付けたMP3(日本語・英語)を置き、アーティストの一覧(3件・「不明」を含む)→
  曲名と曲番号の順で並び、鳴らすと再生中の欄もタグの曲名。**実機では未確認(曲の多いSDで索引を作る速さ)(Todoist参照)**。
- 未: アルバムアート、WAV(LIST/INFO)のタグ、アーティスト→アルバムの2段の一覧、64件を超える一覧。

## 続きから鳴らす (`MusicService::HasResume` / `Resume` / `/sys/music_resume.cfg`) (2026-11-05)

音楽再生に特化した版の強化の5つ目。電源を切っても(電池を抜いても)、前回の曲の続きから鳴らす。

- **書くもの**(`/sys/music_resume.cfg`): `list = all|folder|artist|album`・`name`(フォルダ名・タグの名前)・`folder`(曲のフォルダ名)・`file`・
  `title`・`position-ms`。一時ファイル(`music_resume.tmp`)へ書いてから差し替える(書きかけで電源が切れても前の内容が残る)。
- **書くとき**(`MusicService::Update()` ほか): 曲を鳴らし始めた・曲が変わった・鳴らしている間は約10秒ごと(位置が秒で変わったときだけ。
  急に電源を切ってもずれは10秒まで)・一時停止・止める・スリープタイマーで止まる。「この曲の終わりで止める」は順番だけ次の曲へ進めてそこを書く
  (次の夜は次の曲から)。**最後まで鳴らし終えたら消す**(続きは無い)。位置はWAV/MP3だけ(MMLは位置へ飛べないので曲の頭から)。
- **続きから鳴らす(`Resume()`)**: 順番が無いとき(起動した後)の `TogglePlay()` が呼ぶ。`MusicLibrary` で同じ並び(すべて・フォルダ・
  アーティスト/アルバム)を作り直し、同じフォルダ・ファイル名の曲から鳴らして、WAV/MP3は位置へ飛ぶ。曲が無くなっていれば並びの頭から、
  並び(フォルダ)が無くなっていれば鳴らせない(false)。並びを作る間だけ約7KBを確保する(1コア目のスタックに置けないため)。ミックスの並びは混ぜ直し。
- **見せ方**: ミュージックアプリの再生中の欄に曲名と「前回の続き(1:23 から)」、▶で続きから鳴らしてその並びを開く。ロック画面(曲名と▶。
  `LockFunctions::media_state` が続きでも真を返す)とホームの音楽ウィジェット(曲名と「前回の続きから」と▶だけ)でも、▶で続きから鳴る。
- 検証: `background_test`(鳴らし始めで曲を書く・一時停止で位置を書く・起動し直した(状態を返した)後も続きがあり曲名と位置・再生で同じ並びを作り直して
  その曲のその位置から・最後まで鳴らすと消える・フォルダが無くなっていれば鳴らせない・「この曲の終わりで」は順番を次の曲へ)。PCビルド: 続きの設定を置いて
  起動すると欄に「前回の続き(0:01 から)」、▶でアーティストの並びの2曲目を1.5秒から鳴らし、その並びを開く。
  **実機では未確認(電池を抜いて差し直した後に続きから鳴るか)(Todoist参照)**。
