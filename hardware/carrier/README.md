# pico-os キャリアボード v0.1

Raspberry Pi Pico 2 W と、今までジャンパワイヤでつないでいたモジュールを1枚の基板に載せるための基板(KiCad 8、2層)。
**基板自体はほとんど機能を持たず、モジュールをつなぐだけ**。ピンの割り当てはファームの `src/consts.hpp` と同じ。

> **今の状態: 部品の配置・結線・GNDのベタまで。信号の配線はまだ引いていない**(下の「配線」)。
> 仮の部品(下の表の「仮」)は、実物の写真を見てから形とピンの並びを直す。

設計の経緯と決めたことは `docs/design/carrier-board.md`。

## ファイル

| ファイル | 中身 |
|---|---|
| `pico-os-carrier.kicad_pro` / `.kicad_sch` / `.kicad_pcb` | KiCad のプロジェクト・回路図・基板 |
| `lib/pico-os-carrier.kicad_sym` / `lib/pico-os-carrier.pretty/` | 自作の記号と部品の形(モジュール・Pico・液晶) |
| `sym-lib-table` / `fp-lib-table` | 上の自作ライブラリを `${KIPRJMOD}` から読む |
| `tools/gen_carrier.py` | 初版を生成したスクリプト(**KiCadで手直しを始めたら回さない**。手直しが消える) |
| `tools/check_pins.py` | 回路図の結線を `src/consts.hpp` と突き合わせる(回路図を直したら回す) |

## 基板の形

- 外形 56 x 116 mm、2層、1.6mm。表から見て上に液晶、下端に Pico 2 W が横向き(USBが左、アンテナが右)。
- **表**: 液晶(MSP2807)だけ。14ピンと4ピン(SD)をピンソケットで受け、四隅のM3の穴(液晶の穴と同じ位置)をスペーサーで留める。
  液晶の裏のSDスロットは表から見て左の縁にあるので、液晶と基板のすき間からカードを差す。
- **裏**: Pico・LiPo SHIM・PCM5102A・MAX98357A・マイク・RTC・コネクタ・ジャンパー。
- **アンテナの下は基板を切り欠いた**(右下の切り込み)。切り込みの上下の細い所にもGNDのベタは敷かない。
- GNDのベタは両面。太さの決まり: 電源(GND/VSYS/VBUS/+3V3/LCD_VCC/PCM_VCC/GROVE_VCC)は0.8mm、ほかは0.25mm。

## 部品

| 番号 | 部品 | 面 | 備考 |
|---|---|---|---|
| U1 | Raspberry Pi Pico 2 W | 裏 | 1x20のピンソケット2本で抜き差し |
| U2 | LiPo SHIM for Pico | 裏 | Picoに重ねず、同じ番号のピンを基板で結ぶ。使うのは 3/36/37/38/39/40 番だけ。**向きは仮**(下の「確かめること」) |
| U3 | MSP2807(ILI9341 2.8インチ、タッチ・SD付き) | 表 | 寸法は lcdwiki の `MSP2807_Size.pdf` |
| U4 | MAX98357A モジュール | 裏 | **仮**: Adafruit 3006 と同じ並び(LRC/BCLK/DIN/GAIN/SD/GND/VIN)と仮定。VIN=VSYS |
| U5 | PCM5102A モジュール | 裏 | **仮**: 外形32x17だけ合わせた。端子の並びは写真を見て直す |
| U6 | SPH0645LM4H ブレークアウト | 裏 | **仮**: Adafruit 3421 互換と仮定。音の穴が外を向くよう部品面を基板側にして付ける。SEL=GND |
| U7 | DS3231 + AT24C32(ZS-042) | 裏 | **仮**: 6ピン(32K/SQW/SCL/SDA/VCC/GND)。VCC=3.3V |
| J1 | CardKB2 用 Grove(JST PH 4ピン、HY2.0の代わり) | 裏 | 1=黒GND 2=赤VCC 3=黄SDA 4=白SCL。**差す前にケーブルの色と並びを確かめる** |
| J2 | Qwiic(Wiiヌンチャク変換基板) | 裏 | GND/3V3/SDA/SCL |
| J3 | イヤホンの差し込み検出(GP8・GND) | 裏 | ジャックの検出接点をここへ配線する(差すとGNDへ落ちる向き) |
| JP1〜3 | 液晶・PCM5102A・CardKB2 の電源の選択 | 裏 | 既定は 1-2(3.3V)。2-3 にすると VSYS |
| JP4 | Groveの白線 | 裏 | 既定は 1-2(SCL、I2Cモード)。UARTモードは 2-3(GP7) |
| JP5 | Groveの黄線をSDAへ | 裏 | 既定はつなぐ。UARTモードでは切る |
| JP6 | アンプの検出(GP5をGNDへ) | 裏 | 既定はつなぐ。アンプを載せないなら切る |
| R1, R2 | I2Cのプルアップ 4.7k | 裏 | 普段は載せない(モジュールにある) |

スピーカーはMAX98357Aの端子台へ直接つなぐ(基板には端子を設けない)。電池はSHIMのJSTへ差す。

## 配線

信号の配線はまだ引いていない。KiCad で `pico-os-carrier.kicad_pcb` を開き、

1. 仮の部品の形を写真に合わせて直す(`lib/pico-os-carrier.pretty/`。直したら基板で「フットプリントを更新」)。
2. 配線を引く(手で、または Freerouting のプラグインで自動に)。電源のネットは0.8mmの決まりが付いている。
3. `B` キーでベタを埋め直し、DRC(回路図との照合を入れて)を通す。
4. `python3 hardware/carrier/tools/check_pins.py` で結線がファームと合っているかを見る。

## 確かめること(実物でしか分からないもの)

- **LiPo SHIM の向き**: 基板の形は「SHIMの部品面(JSTとボタンがある面)が外を向く」と仮定し、Picoの裏に重ねたときと穴の対応が鏡映になるように並べた。
  JSTとボタンが文字の面にあるなら左右を入れ替える(1〜7番と34〜40番の列が逆になる)。**ここを間違えると VBUS/VSYS が GP0〜GP5 につながる**。
- 仮の部品(U4〜U7)のピンの並びと外形。
- ZS-042 は CR2032 を充電する回路(ダイオードと抵抗)が付いていることが多い。CR2032を使うなら外す。
- 電源ボタン(SHIM)で切れるのは 3V3_EN だけ。VSYS につながる物(MAX98357A・C1・JPでVSYSを選んだ物)は電池につながったまま。
