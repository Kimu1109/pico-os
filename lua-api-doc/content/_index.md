---
title: "pico-os Lua API"
---

`pico-os` は Raspberry Pi Pico 2 W (RP2350) 上で動く自作タッチGUI OSです。SDカードに Lua スクリプトを置くだけで、ランチャから起動できるタッチGUIアプリを作れます。

このサイトは、`pico.*` として公開されている Lua API の使い方とリファレンス、実際に動くサンプルをまとめたものです。**Luaでアプリを書く人**に必要なことだけを載せています(OS本体の作りは [リポジトリ](https://github.com/Kimu1109/pico-os) の `docs/` を見てください)。
