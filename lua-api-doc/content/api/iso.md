`pico.iso` は、斜め上から見た(アイソメトリックの)マインクラフト風の箱庭を動かす C++ のエンジンです。Luaアプリ「ブロック」(`/lua/apps/ブロック/`。TheScienceElf/Blocks-TI-84 の移植)のために、Luaで書いていた描画とワールドの処理を C++ へ移したものです。アプリは画面の流れと操作だけを書きます。

- **ワールド**: 1辺 1024 マス(8x8 の柱 = 1チャンクが 128x128 個)× 高さ 16。見えている所のまわりのチャンク(最大 56 個。松明の明るさと、その計算の作業場所を含めて約80KB)だけを読み込み、離れたものは手放す。地形は種と位置だけで決まるので、SDへ書くのは書き換えたチャンクだけ
- **描画**: 影(太陽は左奥の上。面を三角形2つに分けて半分だけの影も)、松明の光、昼と夜、半透明の水、水面は2px低く、手前のブロックに完全に隠れるブロックは描かない
- **引き当て**: 画面のタップ位置に見えているブロックとその面
- **人や物**: 好きな画像を箱庭の中に立てて置ける。ブロックとの前後(壁の裏に回ると隠れる)と足元の影はエンジンが描く

ブロックの番号は 0=空気、1=水、2〜24 が石・草・土…(元の Blocks-TI-84 と同じ並び)、25=松明。

## 松明の光

松明(25)は光源です。松明のマスを明るさ7とし、光を通すマス(空気・水・葉・松明)を1マス進むごとに1ずつ暗くしながら広げます(マインクラフトと同じ考え方)。石などの透けないブロックは光を通さないので、壁の裏は暗いままです。光は6マス先まで届きます。

- 面の明るさは、その面が向いている隣のマス(上面なら真上、左面なら -x、右面なら -z)の明るさで決まります
- 明るさは4段階に丸めます: 2マス以内は日なたと同じ絵、3〜4マスは影の絵の上に日なたの絵を市松模様で重ね、5〜6マスは4画素に1つだけ重ねます
- 日の当たる面は、昼はもともと日なたなので変わりません。影になっている面と、いつも影の右面が明るくなります
- `iso.sunlight(false)` で夜にすると、どの面も影の絵で描き、松明の光が届く所だけが明るく見えます
- 松明は影を落とさず、後ろのブロックも隠しません。松明そのものはいつも同じ明るさで描きます
- 明るさは保存しません(チャンクを読み込むときに、まわりの松明から計算し直します)

## はじめの一歩

```lua
local iso = pico.iso
local img = pico.image_load(pico.path_join(pico.app_dir(), "faces.pimg"))
iso.set_image(img)                 -- 面の絵(224x598、1種類につき高さ23pxの1段)
iso.sky(7)                         -- 空の色(パレット番号)
iso.view(0, 20, 240, 204)          -- 表示範囲(Canvas と同じ矩形)

local dir = pico.path_join(pico.app_dir(), "worlds/A")
pico.sd_mkdir(dir)
local x, y, z = iso.create(dir, 0, 12345)  -- 自然のワールド(種 12345)。始めのカーソルの位置
iso.cursor(x, y, z, true)
-- (x, y, z) を表示の真ん中へ
iso.origin(120 - 16 - 16 * (x - z), 122 - 16 + 8 * (x + z) + 16 * y)

local view = pico.create("Canvas")
pico.set(view, "x", 0); pico.set(view, "y", 20); pico.set(view, "w", 240); pico.set(view, "h", 204)
pico.on(view, "render", function() iso.render() end)

function loop(dt)
    -- 見えている所のチャンクを少しずつ読み込む(視点が変わっていれば範囲を決め直す)
    if iso.pump(8, 10) > 0 then pico.invalidate(view) end
end
```

## ワールド

| 関数 | 説明 |
|---|---|
| `iso.create(dir, kind, seed[, k])` → `x, y, z` \| `nil, 理由` | 新しいワールド。`kind`: 0=自然 1=平ら 2=デモ 3=空。`k` は1辺のチャンク数(既定128、1〜128)。始めのカーソルの位置を返す |
| `iso.open(dir)` → `x, y, z, ブロック` \| `nil, 理由` | `dir/world.dat` を開く。保存したカーソルの位置と選んでいたブロック |
| `iso.info(path)` → `種類, 1辺のマス数` \| `nil` | `world.dat` の見出しだけ読む(ワールドを選ぶ画面に) |
| `iso.save(x, y, z, ブロック)` → `bool` | 書き換えたチャンクと見出しを書き出す |
| `iso.close()` | 閉じる(書き出さない。置き場のメモリも返す) |
| `iso.migrate(古いファイル, dir)` → `true` \| `nil, 理由` | 前の版の「ブロック」の保存(48x16x48 を1ファイル)を移し、古いファイルを消す |
| `iso.get(x, y, z)` / `iso.set(x, y, z, ブロック)` | ブロックを読む/書く。世界の外と読み込んでいないチャンクは空気。`set` は読み込んでいなければその場で読み込む |
| `iso.first_air(x, z)` | 下から見て最初の空気の高さ |
| `iso.size()` → `1辺, 16, 種類` \| `nil` | 開いていなければ nil |
| `iso.pump(max[, ms])` → 読み込んだ数 | 予定のチャンクを最大 `max` 個読み込む(`ms` を過ぎたら途中でやめる)。視点が変わっていれば先に範囲を決め直す |
| `iso.pending()` | 読み込む予定の残り |
| `iso.stats()` | `{ chunks, bytes, faces, pending }`(`faces` は直前の `render` で描いた面の数) |

`dir` は `pico.sd_write` と同じ権限の確認を通ります(`permission_sd_outside_app_dir` が無ければアプリのフォルダの中だけ)。ファイルは `dir/world.dat`(見出し17バイト + 書き出したチャンクの印)と `dir/c_<cx>_<cz>.dat`(チャンク)。

## 表示

| 関数 | 説明 |
|---|---|
| `iso.set_image(handle)` | 面の絵(`pico.image_load` したもの、224x598 以上)。透けないブロック(手前に置くと後ろを完全に隠し、光も通さない)を絵から調べておく |
| `iso.view(x, y, w, h)` | 表示範囲。読み込む範囲と、描き直す範囲の切り取りに使う |
| `iso.origin([ox, oy])` → `ox, oy` | ブロック(0,0,0)の絵の左上。ブロック(x,y,z)の絵(32x31)の左上は `(ox + 16*(x-z), oy - 8*(x+z) - 16*y)` |
| `iso.cursor(x, y, z[, show])` | カーソルの位置と表示 |
| `iso.sky(色)` | `render` が塗る空の色 |
| `iso.sunlight([on])` → `on` | 日の光。`false` で夜(描き直しは呼び出し側で `pico.invalidate`) |
| `iso.light(x, y, z)` → `0〜3` | そのマスの松明の明るさ(0=届かない、3=日なたと同じ) |
| `iso.render([x, y, w, h])` | 空で塗ってワールドとカーソルを描く。**Canvas の `render` の中で呼ぶ**(省略すると今の描き直す範囲) |
| `iso.draw_icon(ブロック, x, y)` | 1個のブロックをまるごと描く(ボタンや選ぶ画面に) |
| `iso.block_pos(x, y, z)` → `px, py` | ブロックの絵の左上 |
| `iso.pick(px, py)` → `x, y, z, 面` \| `nil` | 画面の点に見えている一番手前のブロックと面(`"top"` `"left"` `"right"`) |
| `iso.dirty_block(x, y, z)` | そのブロックの絵の所を描き直す(カーソルを動かしたとき) |
| `iso.dirty_edit(x, y, z)` | 置いた/壊したとき。そのブロックと、影が変わりうる面と、松明の明るさが変わった範囲だけを描き直す |
| `iso.culling(bool)` | 隠れたブロックを描かない(既定 true。比べるとき用) |

## 人や物(エンティティ)

箱庭の中の好きな位置(小数でよい)に、画像を立てて置けます(32個まで)。人・動物・樽など、ブロックの格子に乗らないものに使います。

- 位置 `(x, y, z)` は**足元の中心**です(ブロックの単位。`y` は足の裏の高さ)。ブロック `(bx, by, bz)` の上に立たせるなら `(bx + 0.5, by + 1, bz + 0.5)`
- 絵は「足元の点」(既定は絵の下の真ん中)がその位置に来るように置きます
- **ブロックとの前後**は「当たりの箱」(足元を中心にした半径 `r` の正方形 × 高さ `height`)で決めます。箱とブロックが離れている向きで、見る人の側(左手前 `-x`・右手前 `-z`・上 `+y`)にある方が手前です。壁の裏に回ると隠れ、柱の手前に出ると柱を隠し、1段のブロックの奥では足元だけが隠れます。水の中では、水面より下だけが水越しに見えます
- **影**: 足元の下の地面(上面が足の裏以下の一番上のブロック)に、丸い影を市松模様で落とします。高く上がるほど小さくなります。壁の裏の地面に落ちた影は壁が隠します
- 位置や絵を変えると、前の所と今の所を自動で描き直します(`pico.invalidate` は要りません)
- 画像は `pico.image_load`(透過つきの `.pimg`。0番が透過)や `pico.image_create(w, h, true)` で作ったもの。画像を解放すると、その人や物は描かれなくなります
- ワールドを閉じる(`iso.close`、`iso.create`、`iso.open`)と全部片付きます
- 夜(`iso.sunlight(false)`)でも絵はそのままの明るさです

| 関数 | 説明 |
|---|---|
| `iso.entity_add(image, x, y, z[, opts])` → `id` \| `nil, 理由` | 置く。`opts` は下の表 |
| `iso.entity_set(id, opts)` | 変える(`opts` に書いたものだけ。おかしな値ならエラーで、何も変えない) |
| `iso.entity_move(id, x, y, z)` | 動かす(`entity_set` より軽い。毎フレーム呼んでよい) |
| `iso.entity_get(id)` → `x, y, z, 表` \| `nil` | 位置と、今の `opts` の値をまとめた表 |
| `iso.entity_remove(id)` → `bool` / `iso.entity_clear()` | 取り除く / 全部取り除く |
| `iso.entity_at(px, py)` → `id` \| `nil` | 画面の点にある一番手前の人や物(絵の不透明な画素で判定。ブロックに隠れているかは見ない) |
| `iso.ground(x, z[, y])` → 高さ \| `nil` | 柱 `(x, z)` で、上面が `y`(省略すると一番上)以下にある一番上のブロックの上面の高さ。水も地面(水の中なら水の底)、松明は地面にならない |
| `iso.to_screen(x, y, z)` → `sx, sy` | 点の画面の位置(小数のまま) |

`opts`:

| キー | 既定 | 説明 |
|---|---|---|
| `x` `y` `z` | — | 位置(`entity_set` のとき) |
| `image` | — | 画像を差し替える(`entity_set` のとき) |
| `sx` `sy` `w` `h` | 画像全体 | 画像の中の範囲(コマを並べた画像の1コマ)。大きさが変わると `ax` `ay` を決め直す |
| `ax` `ay` | `w // 2`, `h - 1` | 足元の点(範囲の左上から) |
| `r` | `w / 64`(0.05〜0.49) | 当たりの箱の半径(ブロックの単位)。絵の横幅の画面の幅が `64 * r` |
| `height` | `h / 16` | 当たりの箱の高さ(ブロック1段が16px) |
| `flip` | `false` | 左右反転 |
| `visible` | `true` | 隠す |
| `shadow` | `true` | 足元に影を落とす |
| `shadow_color` | `0` | 影の色(パレット番号) |

```lua
local people = pico.image_load(pico.path_join(pico.app_dir(), "people.pimg"))
local x, z = 520.5, 512.5
local y = iso.ground(x, z)                       -- 立てる地面の高さ
local id = iso.entity_add(people, x, y, z, { w = 12, h = 22 })   -- 1コマ目(12x22)

function loop(dt)
    x = x + 1.5 * dt / 1000                      -- 右奥(+x)へ 1.5 ブロック/秒
    local g = iso.ground(x, z, y + 1.01)         -- 1段なら登れる
    if g and g <= y + 1 then y = g end
    iso.entity_move(id, x, y, z)                 -- 描き直しは自動
end
```

Canvas の `render` で `iso.render()` を呼んでいれば、人や物もそこで描かれます。アプリ「ブロック」の `mobs.lua`(村人と羊が歩き回り、タップで跳ねる)が使い方の例です。

## 速さ

描画は C++ で、面の絵は 4bpp のバッファどうしで写します。透けないブロックの面は「上面のひし形・左右の平行四辺形」の形どおりなので、1行を1区間として透過の判定なしに `memcpy` します(葉・水・カーソルだけ1画素ずつ)。手前の透けないブロック `(x-k, y+k, z-k)` は画面のちょうど同じ六角形に重なるので、その後ろのブロックは描きません(省いても画素が1つも変わらないことをテストで確かめています)。PCでの計測では、Lua版の描画の処理(絵を写す前まで)の約55倍の速さで、表示全体で描く面は約3割減りました。

人や物は、ブロックを描いた後に奥から順に描き、手前のブロックだけを絵の不透明な画素の上へ1画素ずつ描き直します(描き直す範囲は絵の矩形の中だけ)。
