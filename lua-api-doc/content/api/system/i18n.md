本体の表示言語は設定アプリの「他」→「言語/Language」で選べます(今は日本語と英語。Webでは `?lang=en` やブラウザの言語)。
アプリも同じ言語で見せたいときは、画面に出す文字を `pico.tr()` で包み、訳を `lang/<言語>.lua` に置きます。

## pico.lang()

今の表示言語のコード(`"ja"` か `"en"`)を返します。

```lua
if pico.lang() == "en" then ... end
```

## pico.tr(text [, ...])

`text` の今の言語での訳を返します。訳はアプリのフォルダの `lang/<言語>.lua` から引きます。
**訳が無ければ `text` をそのまま返す**ので、訳し漏れがあってもアプリは止まりません。

引数を足すと `string.format(訳, ...)` した結果を返します。数字を文の途中に入れるときは、`..` でつながず書式にしてください
(言語によって語順が変わるため)。

```lua
pico.draw_text(8, 8, pico.tr("スコア:%d", score), 0, 1)
local btn = g:button{ name = "reset", label = pico.tr("リセット") }
```

- 表は最初の `pico.tr()` で1回だけ読みます。アプリを開いている間に言語が変わることはありません
  (本体の言語を変えるには設定アプリへ移るので、戻るとアプリは開き直されます)
- `text` が原文(キー)です。原文の言語は何でもかまいません。英語で書いたアプリに `lang/ja.lua` を置けば日本語の画面で訳されます

## lang/<言語>.lua

「原文 → 訳」の表を `return` するだけのファイルです。

```lua
-- lang/en.lua
return {
    ["スコア:%d"] = "Score: %d",
    ["リセット"] = "Reset",
    ["タップで開始"] = "Tap to start",
}
```

- 書式(`%d` `%s` など)は原文と同じ順に並べてください
- 32KBまで。空の環境で実行されるので、`pico.*` やアプリのグローバル変数には触れません(表を返すだけ)
- 読めない・表を返さないファイルはログに警告を出して無視します(原文のまま)
- 本体の画面と同じく、画面は240px幅です。訳はなるべく短く

## 名前と説明(app.cfg の name_en・description_en)

```ini
name=テトリス
name_en=Tetris
description=pico.gameで作ったテトリス風ゲーム。タッチと外部コントローラーで遊べる
description_en=A Tetris-style game made with pico.game. Play with touch or an external controller
```

- `name_en` があれば、英語の画面のときにランチャ・長押しのメニュー・アプリストアへその名前を出します(23バイトまで)。
  `name` は `pico.launch_app` や並びの保存で使う**識別子**なので、言語で変えないでください
- `description_en` があれば、本体のアプリストア(英語の画面のとき)と、Webのアプリストアのページ(English のとき)に
  その説明を出します(180バイトまで)
- どちらも無ければ `name`・`description` のまま出ます。片方だけでもかまいません
- アプリストアの一覧(catalog.tsv)は1行640バイトまでなので、名前と説明(原文と訳)が長すぎると、
  配るときに `description_en` の後ろが切り詰められます(警告が出ます)

## 訳のファイルを作る

pico-os のリポジトリの `script/i18n.py` が、アプリの `pico.tr("…")` を拾って `lang/en.lua` を作り直します。

```sh
python3 script/i18n.py lua path/to/my-app
```

- 書いた訳はそのまま残し、まだ訳の無い原文は `-- TODO ["原文"] = "",` の行で足します。TODO の行は使われない(原文のまま出る)ので、
  `-- TODO ` を消して `""` の中へ訳を書いてください
- 使われなくなった原文の行は消えます
- テスト(`picoos lua-test`)の偽物の `pico.tr` は既定で原文を返します。英語で確かめるときは `load_app{ lang = "en" }` のように渡します
