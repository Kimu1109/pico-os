03

INSIDE

しくみ 520KB SRAM

WIDGETS

ウィジェット・シーン・ダイアログ・キーボード3種まで、GUIフレームワークを自前で実装。書き換わった所だけを合成して液晶へ送ります。

NO HEAP STRINGS

文字列はヒープを使わない固定長。部品はオブジェクトプールで使い回し、小さなRAMで断片化を起こさない作りに。

DUAL CORE

1コア目が画面と入力、2コア目は音声だけを担当。チップチューン・ゲームボーイの音・マイク録音をI2Sで。イヤホンを差すとスピーカーから自動で切り替わります。

JAPANESE

日本語の表示とかな漢字変換を内蔵。オンスクリーンキーボードのほか、CardKB2などの物理キーボードもつながります。

NETWORK

Wi-Fi・HTTPS・SSH・IMAP。Wi-Fiの設定はスマホからも送れ、picoos.local の名前で見つかります。認証情報は端末ごとの鍵で暗号化して保存。ファームウェアの更新もSDやWi-Fiから。

SAME CODE

実機とおなじソースを、PC(SDL)とブラウザ(WebAssembly)でも動かせます。差し替えるのはハードの窓口だけ。画面の大きさや載せる部品もビルド時に選べます。

04

LUA

Luaでアプリを作る PICO.*
  • SDカードの /lua/apps/<名前>/main.lua に置くだけで、ホーム画面にアプリが増えます。
  • pico.* でウィジェット・描画・タッチ・音・SD・ネットワークを扱えます。
  • ゲーム用の pico.game、2.5Dエンジン pico.iso も。
  • 暴走しても止まる実行時間の上限と、アプリごとの権限つき。
  • PCビルドでは保存するたびに読み直すホットリロードと、テストランナーで手早く試せます。
