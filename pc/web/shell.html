WI-FI 状態を差し替えて再読み込み

URLのクエリがそのまま環境変数になる(?wifi=disconnected&rssi=-85)。 使えるキーは wifi / rssi / ssid / scan。

PAD 外部コントローラー

画面の下のボタン(マウス・複数の指で同時押しも可)か、キーボードで操作する。 実機では USB シリアルの script/pad_serial.py が担う部分で、同じ pad XXXX の行を pico-os へ流している(チェックを外すと 0.5 秒で「外れた」扱いになる)。

十字キー = 矢印 / A = X / B = Z / X = S / Y = A / L・R・ZL・ZR = Q W E R / START = Enter / SELECT = Backspace / HOME = H か Esc

「PCのキーボード」を文字入力にすると、打ったキーを物理キーボードとして送る (key M u+XXXX の行。実機では pad_serial.py --mode text と同じ)。 オンスクリーンキーボードを開いている所・テキストエディタ・SSH にそのまま入る (Ctrl+C 等も送るので、ブラウザのショートカットは効かなくなる。Cmd/⌘ 付きはブラウザへ渡す)。
