# pico.iso のテストの面の絵

`faces.pimg` は、標準のLuaアプリ「ブロック」(kimu1109/pico-os-apps の `apps/blocks/app/faces.pimg`)の2026-11-07の写し。
`iso_world_test`・`iso_td_test`・`lua_ext_test` が、本物の大きさと透過の面の絵として読む(アプリの絵が変わっても、ここは変えなくてよい)。

元の絵は TheScienceElf 氏の Blocks-TI-84(MIT。`script/assets/blocks_assets/LICENSE-Blocks-TI-84.txt` の写しを同じ所に置く。
作り方は pico-os-apps の `script/assets/generate_blocks_sheet.py`)。
